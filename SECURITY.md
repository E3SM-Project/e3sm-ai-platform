# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities in E3SM AI Platform or E3SM Compass through
[GitHub private vulnerability reporting](https://github.com/E3SM-Project/e3sm-ai-platform/security/advisories/new).
You can also open the repository's **Security → Advisories** page and select
**Report a vulnerability**.

Do not report vulnerabilities, exploit details, or sensitive data in public
issues, discussions, or pull requests. Private vulnerability reports are not
public GitHub issues.

Include the affected component and commit or release version, the potential
impact, and minimal reproduction steps. Use sanitized examples; do not include
credentials, private keys, sensitive prompts, or unapproved proprietary data.

Use the private report to coordinate investigation, fixes, and any public
disclosure with the maintainers.

## Other reports and questions

Use [GitHub Discussions](https://github.com/E3SM-Project/e3sm-ai-platform/discussions)
for usage and setup questions. Use the repository's issue templates for
non-security bugs, enhancements, documentation, DevOps, planning, and refactoring.
